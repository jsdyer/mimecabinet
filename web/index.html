A reference, not a registry verdict

The bundled mime-db maps media types to known extensions and records IANA, Apache or nginx provenance when available. Multiple types can share an extension. Its compressibility flag describes typical content, not an HTTP Content-Encoding already applied.

Dataset edition · MIT licence

A bounded header inspection

The first bytes are compared with a small, documented collection of format patterns. ZIP, Ogg and ISO media containers can hold several formats. Archives are not extracted, content is not executed, and unknown signatures stay unknown.

A file can be damaged, truncated, misleading or contain additional content despite a matching header. This is not a malware scanner.

Keep the original local

Queries, header values, filenames and file bytes stay in this tab. The app loads its own static reference files and CoolCode’s shared usage counter. It stores no inputs automatically. Download an inspection JSON if you want to retain one; that file includes the filename and first 64 bytes.
